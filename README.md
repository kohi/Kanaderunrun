# Kanaderu（カナデル）

音楽・写真・動画をセクションごとに配置し、1本のMP4ムービーを作るWebアプリです。素材の解析、プレビュー、動画の書き出しはブラウザ内で行います。

## 主な機能

- **音楽から尺を確定**：楽曲を読み込み、試聴・トリミングしてからセクション構成へ進みます。
- **2つのBGMモード**：1曲を全セクションで通して再生するモードと、セクションごとに楽曲を指定するモード。
- **セクション編集**：追加、名前変更、削除、並べ替え。写真・動画・表紙・エンドカードを個別に配置できます。
- **時間の自動配分**：通し再生では、手動指定の時間を差し引いた残りを自動セクションに配分。曲と映像の尺が合わない場合は書き出しを止めます。
- **写真の配置・差し替え**：ドラッグで並べ替え、外部画像をカードへドロップして差し替え。固定秒数と切り替え効果を保持します。
- **動画挿入**：使用範囲のトリミングと元音声の音量設定。元音声は初期設定でミュートです。
- **自動演出**：写真の並べ替えを含む4つのおまかせパターンと、順番・秒数を変えない「効果だけおまかせ」。
- **保存・復元**：写真・動画・楽曲を含む編集状態を、同じブラウザに1件保存できます。
- **プレビュー・MP4出力**：横16:9／縦9:16、HD／FHD／4K、全画面表示、映像・音声フェードに対応。

## 使い方

1. 音楽を読み込み、使用する開始・終了位置を調整します。
2. 「楽曲の尺を確定してセクション設定へ」または上部の「セクション構成」を押します。
3. セクションを追加し、写真・動画・表紙を配置します。秒数を直接入力すると、そのセクションだけ手動指定になります。
4. 必要に応じて「効果だけおまかせ」を使い、全体をプレビューします。
5. 「MP4を書き出す」で生成し、ダウンロードします。後日再開する場合は「編集状態を保存」も押してください。

詳しくは [セクション編集ガイド](docs/SECTION_EDITING.md) を参照してください。

## ローカルで起動

Node.js 22.12以上の22系、またはNode.js 24系を推奨します。動作確認にはNode.js 24を使用しています。

```bash
git clone https://github.com/kohi/Kanaderunrun.git
cd Kanaderunrun
npm ci
npm run dev
```

ターミナルに表示されるURLを開きます。通常は `http://localhost:5173/` です。MP4出力にはH.264／AAC対応のWebCodecsが必要なため、ChromeまたはEdgeでの利用を推奨します。

```bash
npm test         # ユニットテスト
npm run lint     # 静的解析
npm run build    # dist/ に本番用ファイルを生成
npm run preview  # ビルド結果をローカル確認
```

## 素材と保存について

- 音楽：MP3、M4A、WAVなど、ブラウザでデコードできる音声。
- 写真：JPEG、PNG、WebP、HEIC／HEIF。大きな写真は長辺2304pxを上限に縮小します。
- 動画：MP4、WebM、MOVなど、ブラウザで再生できる映像。拡張子だけでは対応を保証できません。
- アプリは素材をサーバーへ送信しません。バックエンドやAPIキーは不要です。
- 「編集状態を保存」はIndexedDBを使う手動保存です。次回保存で上書きされ、未保存の変更は再読み込みで失われます。
- 保存内容は同じブラウザ・同じサイトでのみ復元できます。別端末への同期や保存ファイルの持ち出しには未対応です。サイトデータの削除や保存容量不足にもご注意ください。

## 公開方法

`npm run build` で作成した `dist/` の内容を、HTTPS対応の静的Webサーバーへ配置します。相対パスでビルドするため、サブフォルダへの配置にも対応します。さくらのレンタルサーバーなどApache環境向けに `public/.htaccess` を同梱しています。

GitHubへのソースコード登録だけではWebサイトは公開されません。詳しい手順と注意点は [開発・検証・配備ガイド](docs/DEVELOPMENT.md) を参照してください。

## 技術構成

React 19 / TypeScript / Vite 7 / Tailwind CSS 4 / Web Audio API / Canvas 2D / WebCodecs / mp4-muxer / IndexedDB。テストはVitestを使用しています。
