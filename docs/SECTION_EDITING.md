# セクション編集ガイド

## 作成の流れ

1. 最初にステップ1で音楽を読み込み、開始位置・終了位置をトリミングします。標準は「1曲を全体で通して使う」です。
2. 表示された動画全体の尺を確認し、「この尺で確定してセクション構成へ」を押します。この操作で楽曲の使用範囲が全体の尺として確定します。画面上部の「楽曲の尺を確定してセクション設定へ」、ヘッダーの「セクション構成」からも同じ操作で進めます。
3. ステップ2でセクションを追加します。初期セクションは曲の使用時間全体を受け取り、追加時は残り時間を自動配分します。秒数欄への直接入力で、そのセクションだけ手動指定できます。
4. 各セクションへ写真・動画・表紙・エンドカードを追加します。動画の秒数ボタンから使用範囲と元音声を設定できます。
5. セクションカードの矢印で章を並べ替えます。ステップ3で全体をプレビューし、MP4を書き出します。
6. 後から音楽やトリミングを変更する場合も、ステップ1に戻って尺を再確定します。編集途中のトリミングでは既存のセクション時間を変更しません。再確定時は手動秒数を維持し、自動セクションを再配分します。固定時間・素材の最低時間が新しい尺に収まらない場合は不足を表示し、書き出しを停止します。

従来のセクション別の楽曲設定は「セクションごとに設定」へ切り替えて使用できます。

## 1曲を全セクションで通して使う

画面上部「楽曲の使い方」で「1曲を全体で通して使う」を選びます。ステップ1で全体の楽曲と使用範囲を設定し、確定ボタンを押すと、その長さが全体時間になります。楽曲未選択ではステップ2へ進めません。読み込み後は「セクション構成」を押すと現在の使用範囲を確定して進めます。

各セクションの長さは「残り時間から自動配分」または「秒数を指定する」を選べます。秒数欄はどちらでも直接編集でき、数値を入力するとそのセクションが手動指定になります。入力途中の空欄・小数も扱えます。0.1〜3600秒の有効な値を採用し、入力を離れた時に無効な入力は直前の有効な値へ戻します。

手動指定の合計を楽曲の使用時間から引き、残りを自動のセクションへ配分します。動画・表紙・写真に必要な最低時間を確保しながら均等配分します。固定素材だけのセクションは素材の合計時間を使い、余りを他の自動セクションへ回します。楽曲の変更・トリミングは尺の再確定時、セクションの追加・削除や素材の変更は操作時に再計算します。

画面に楽曲の使用時間、手動指定の合計、自動配分に使える残りを表示します。曲の長さを超過する場合や、全て手動指定で時間が余る場合は差分を表示し、書き出しを止めます。意図しない無音の末尾や曲の途中終了を防ぐため、合計を楽曲の使用時間に一致させてください。

楽曲は作品の先頭から一度だけ再生し、セクションの境目では再スタート・フェードを行いません。並べ替え後も楽曲は通して再生され、写真のビート位置は新しい位置に合わせて計算します。作品全体のフェード設定はステップ3で変更できます。

全体モードへ切り替えると、手動指定のセクションはその秒数を維持し、楽曲連動のセクションは残り時間の自動配分に切り替わります。追加するセクションも自動配分が初期設定です。個別の楽曲設定は保持され、「セクションごとに設定」に戻して使えます。動画の元音声も引き続き重ねられます。

## 時間配分

- 表紙・エンドカード、秒数を固定した写真、トリミングした動画の時間を先に確保します。
- 残りの時間を、自動設定の写真へ配分します。自動設定の写真は1枚1.5秒以上必要です。
- 動画の長さや写真の固定秒数を、セクションの長さに合わせて勝手に伸縮しません。
- 固定素材だけの場合、合計秒数とセクションの秒数を一致させてください。「素材の長さに合わせる」で設定できます。自動の写真がある場合、このボタンは写真1枚を3秒として計算します。
- 素材なし、未設定の表紙画像、秒数不足・余りなどは、該当セクション名とともに表示し、書き出しを停止します。
- 写真のみのセクションでは従来のおまかせ並べ替えを利用できます。動画を含む場合は、手動・ファイル名順・シャッフルで並べ替えてください。

## 音楽・音声

以下は「セクションごとに設定」の動作です。全体を通すモードでは上記の時間配分を使います。

- 各楽曲は、トリミング範囲の先頭からそのセクション開始時に再生します。
- セクションが楽曲より短い場合は、セクション末尾でフェードアウトします。
- 楽曲がセクションより短い場合は、楽曲の使用範囲末尾でフェードアウトし、残りの時間はBGMなしになります。自動ループはしません。
- セクションごとにフェードイン・フェードアウトを0〜10秒、音量を0〜100%で設定できます。短い楽曲では各フェードを使用時間の半分以下に収めます。
- セクション境界では前の楽曲がフェードアウトし、次の楽曲がフェードインします。楽曲を重ねるクロスフェードではありません。指定した章の秒数・開始位置は変わりません。
- 動画の元音声を有効にすると、その動画の使用区間の音声をBGMに重ねます。読み取り可能な音声がない場合は映像のみ使用します。
- ステップ3のフェードは作品全体の冒頭・末尾にかかり、セクションごとの楽曲フェードに加えて適用されます。

## 対応と制約

- 動画は使用ブラウザでデコードできる形式に限ります。拡張子がMP4 / MOVでも、映像・音声コーデックによって読み込めない場合があります。
- MP4出力にはH.264 / AAC対応のWebCodecsが必要です。Chrome / Edgeを推奨します。
- 動画を含む出力では、各フレームの読み取りを待って描画します。素材の長さ・解像度や端末性能により処理時間が増えます。
- 編集中の変更は「編集状態を保存」を押して保存してください。未保存の変更は再読み込みで失われます。従来の画質・演出設定の保存も継続します。
- 写真・動画・楽曲はサーバーへ送信しません。

## 実装と検証

- `types/project.ts`: セクションと動画のデータモデル。
- `core/timeline/sections.ts`: セクション別の検証・時間配分と全体タイムライン生成。
- `core/audio/composition.ts`: プレビューとMP4出力に共通の音声スケジュール・フェード処理。
- `core/video/media.ts`: 動画の読み込み、元音声の取得、プレビュー・出力用のフレーム取得。プレビューと出力は別々のデコーダーを使用します。
- `components/SectionEditor.tsx` / `VideoClipEditor.tsx`: セクション構成と動画使用範囲の編集。

自動テストは既存32件に、時間配分・章の並べ替え・表紙のみ／動画のみ・音声範囲・フェードなど44件を追加しています。Chromeで複数セクションの編集、動画トリミング、表紙設定、並べ替え、全体プレビュー、MP4生成・ダウンロードも確認しています。

## 編集状態の保存と復元

「編集状態を保存」で、写真・動画・楽曲の元ファイル、トリミング、セクションの順番・時間、表紙、効果、音量・フェード、画質などをこのブラウザに保存します。保存は1件で、次の保存で上書きします。再読み込み後は「保存した状態を復元」から再開できます。復元時は現在の編集内容を置き換えます。音楽の未確定の編集範囲も保持します。

保存先は同じブラウザ・同じサイトのIndexedDBです。別端末・別ブラウザへは同期しません。ブラウザのサイトデータを削除すると保存内容も失われます。素材の読み込み中・MP4出力中は保存と復元を無効にします。空き容量不足などで保存できない場合はエラーを表示し、成功したとは表示しません。

## 写真のドラッグと効果のみの自動設定

- 同じセクション内のカードをドラッグすると、並び順を変更します。
- 外部の画像ファイルを写真カードへ1枚ドロップすると、その写真を差し替えます。位置・固定秒数・切り替え効果を保持します。
- 複数ファイルや新しい素材は「写真・動画を追加」へドロップします。
- 別セクションからのカードのドラッグは受け付けません。読み込み中にセクションを切り替えても、読み込んだ素材は読み込みを開始したセクションだけに追加されます。
- 「効果だけおまかせ（順番を維持）」は、写真の順番・時間・動画の設定を変更せず、楽曲に合わせて写真の切り替え効果を割り当てます。個別の効果を反映するため、全体のトランジションスタイルは「メリハリ重視」に切り替わります。
